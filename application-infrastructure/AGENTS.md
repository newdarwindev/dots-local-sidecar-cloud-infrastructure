# Staged application bundle

Keep all commands read-only or local rendering by default. No credentials,
permission/network/storage mutations, source enrollment or persistent jobs without
exact current owner approval. Local approval records are guards, not consent.
Run validation only in Docker via the committed workflow. Do not start a daemon
to work around missing Docker. Use synthetic records only. Preserve all original
histories, receipts, PVCs and backups. Keep private target details outside Git.
